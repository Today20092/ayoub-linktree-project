## Production

We shoot on a Sony a7S III and a Lumix S5IIX, light with Aputure and Amaran fixtures, and record dialogue on Hollyland wireless mics. Before each setup I check the lights against the subject and the background, then set exposure with a false-color LUT on the monitor.

That LUT comes from [lut_builder](https://today20092.github.io/lut_builder/), a browser tool I built. It maps each exposure band to a color, so I can see when skin sits where I want it and when highlights are about to clip, without trusting a bright screen outdoors.

## Pipeline

Both cameras record in log. Log keeps more highlight and shadow detail than a baked-in look, which matters on bright Houston exteriors. In DaVinci Resolve, a color-managed timeline converts each camera's log to one working space, so the a7S III and S5IIX shots match before I grade.

Delivery is Rec.709 with Gamma 2.2, not 2.4. Gamma 2.4 suits a dim room with a reference monitor. Most of the Ya Hala audience watches on phones and laptops in normal light, where 2.2 keeps shadows from looking crushed.

## Automation

Resolve's AI noise reduction handles the first cleanup pass on dialogue. I use AI coding agents to write small scripts for repetitive steps, and [Resolve TimeTracker](https://github.com/Today20092/Davinci-Resolve-TimeTracker), another tool I built, logs active editing and render time so I can measure what each change saves.
