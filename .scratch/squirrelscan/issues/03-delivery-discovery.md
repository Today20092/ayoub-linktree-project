# Improve public page delivery and discovery

## What to build

Search engines, visitors, and automated readers receive consistent public URLs, safe caching and security behavior, and accurate contact, about, and privacy information. Private gallery and admin responses remain private.

Source: the September 11, 2026 squirrelscan HTTP audit of https://ayoubabed.xyz, version 0.0.94, 26 pages, score 59. Work is local on the current feature branch; publishing and deployment are outside scope.

## Acceptance criteria

- [x] Investigate and fix applicable findings for `crawl/sitemap-coverage`, `core/title-unique`, `content/duplicate-title`, `content/duplicate-description`, `url/slug-convention`, and `links/no-contextual-inbound`.
- [x] Investigate and fix applicable findings for `security/csp`, `security/sri`, `perf/ttfb`, `perf/bad-caching`, `perf/cache-headers`, and `perf/critical-request-chains`, preserving working scripts, styles, analytics, gallery authorization, and uploads.
- [x] Address `eeat/about-page`, `eeat/contact-page`, `eeat/privacy-policy`, `legal/privacy-policy`, `legal/subprocessor-disclosure`, `ax/llms-txt`, and `ax/markdown-response` using existing factual information and the smallest useful implementation. Do not invent legal promises, retention schedules, or processing agreements.
- [x] Canonical public URLs avoid duplicate gallery routes; public gallery sitemap coverage respects visibility and publication status; admin routes are excluded from indexing.
- [x] Any caching change excludes personalized, authenticated, admin, API, and private responses unless explicitly safe, with focused regression checks.
- [x] Record a disposition for every assigned rule with evidence for false positives, deployment-only validation, or deliberate deferrals. Do not suppress rules.
- [x] Verify the integrated result in a fresh local squirrelscan audit, clearly distinguishing development-only differences from production behavior.
