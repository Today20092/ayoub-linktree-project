## Automated uncertainties and manual review queue

- Axe returned **38 incomplete rule instances / 66 nodes** across the 36 same-site route entries and their two theme/width states. These are unresolved checks, not passes or automatically confirmed defects. Full selectors and rule data are in `.astro/full-ui-review-results.json`.
- Contrast incompletes include transparent unselected coverage checkmarks, labels over gallery cover images and video thumbnail overlays. The checkmarks are intentionally invisible until selected; assess the actual selected mark and discoverability separately. Image overlays need rendered contrast judgment for the images/states in use.
- Payment `.card-tips` and `.payment-options` are generic `div` elements with `aria-label`; axe requests review of `aria-prohibited-attr`. Use a named group/section if a group name is useful, rather than relying on labels on generic containers.
- Tracker plus/minus buttons have purpose-specific accessible labels; axe marks the symbol-versus-name relationship incomplete. Preserve meaningful names and review speech-input behavior before changing them.
- The basic DOM heuristic found one apparently empty admin button, but axe did not flag an unnamed button. An accessible-name investigation is needed before classifying it as a defect.
- Media playback, captions, audio description, actual screen-reader announcements, actual 400% browser zoom, physical mobile/touch use and representative-user task testing remain unavailable. CSS font scaling is not browser zoom. No WCAG conformance claim follows from these scans.
