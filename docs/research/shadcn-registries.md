# Free shadcn registries for this site

Research note, 2026-11-03. Input for the registry decision referenced in `DESIGN.md` (#93). Nothing here is installed; `components.json` still has `"registries": {}`.

## Site constraints

- Astro 7.4, React 19.3, Tailwind 4.3 (`package.json`); shadcn style `radix-rhea`, base color `stone`, lucide icons, `rsc: false` (`components.json`).
- `DESIGN.md`: quiet UI, one emerald accent, no gradients or glass over photos, hover/focus-only motion that respects `prefers-reduced-motion`, no scroll-jacking. Always `<Image />` from `astro:assets`.
- Consequence: any registry item that renders raw `<img>`, `next/image`, or `next/link` must be rewritten before use. Heavy motion libraries conflict with the motion rule on persuade pages (hire page).

## Method

- Source index: `https://ui.shadcn.com/r/registries.json` (530 entries on 2026-11-03, each with a health score) and the directory at https://ui.shadcn.com/docs/directory.
- License and last push: GitHub REST API (`api.github.com/repos/<owner>/<repo>`) and repository LICENSE files.
- Item lists: each registry's `/r/registry.json`, filtered for hero, CTA, contact, pricing, testimonial, gallery, marquee items.
- Install form for all: `npx shadcn add @<namespace>/<item>` (namespaces resolve through the official index; https://ui.shadcn.com/docs/directory).

## Caveats

- `registries.json` health scores measure endpoint reliability, not design quality or license (see `health.breakdown` in the index).
- Licenses marked "per site" were not confirmed from a LICENSE file.
- Next.js check was spot-only (`magicui/marquee`, `cnippet gallery-1`, `tailark hero-section-1`). Run `npx shadcn view @ns/item` before each install and grep for `next/image`, `next/link`, `"use client"`, and `<img`.
- Registry blocks land as React `.tsx`; on Astro they need a `client:*` directive only if interactive. Static blocks are better ported to `.astro` so photos go through `<Image />`.
- Adding a registry means adding it to `components.json` `registries`; that is a separate decision (#93).
