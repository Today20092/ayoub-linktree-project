# Reading Ayoub Abedrabbo's website

Use [/llms.txt](https://ayoubabed.xyz/llms.txt) for the site map and
[/index.md](https://ayoubabed.xyz/index.md) for a text introduction and current
service information. Public page content is the source for project details;
portfolio results describe the reporting periods stated on each case study.

For instant event portraits, read the current
[offer and starting prices](https://ayoubabed.xyz/services/event-portraits/).
The inquiry form opens an email draft. A request does not reserve a date;
availability and the final scope require Ayoub's reply.

Browse published photo collections through
[/galleries/](https://ayoubabed.xyz/galleries/). Hidden and unlisted galleries are
excluded from public discovery. Use an unlisted viewing or upload link only
when its owner has shared it with you; keep its token private. Upload photos
only with the gallery owner's authorization and permission to share them.

Use [/contact/](https://ayoubabed.xyz/contact/) to reach Ayoub about a project or
photo, [/privacy/](https://ayoubabed.xyz/privacy/) for data handling, and
[security.txt](https://ayoubabed.xyz/.well-known/security.txt) for a security
contact. These are public website reading notes, not repository instructions.
